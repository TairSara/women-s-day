### 1. התקנת תלויות
```bash

```


## הוספת תמונות לקטלוג

### גודל תמונות מומלץ:

**📏 מפרט תמונות:**

#### **JPG / WEBP:**
- **רוחב:** 1200 פיקסלים
- **גובה:** 1697 פיקסלים
- **יחס:** 1:1.414 (יחס A4)
- **רזולוציה:** 150 DPI
- **איכות:** 80-85% (JPG) / 85-90% (WEBP)

#### **למסכי Retina (אופציונלי):**
- **רוחב:** 1800 פיקסלים
- **גובה:** 2546 פיקסלים
- **יחס:** 1:1.414 (יחס A4)
- **רזולוציה:** 225 DPI

### פורמטים נתמכים:
- `.jpg` או `.jpeg`
- `.webp` (מומלץ - גודל קובץ קטן יותר)
- `.png`

### שמות קבצים:
השתמש בשמות עם 3 ספרות:
- `001.jpg` - עמוד 1 (כריכה)
- `002.jpg` - עמוד 2
- `003.jpg` - עמוד 3
- ...
- `010.jpg` - עמוד 10 (עמוד אחרון)

### דוגמה להמרה ל-WEBP עם איכות טובה:

#### באמצעות Photoshop:
1. File → Export → Save for Web
2. בחר WEBP
3. איכות: 85-90
4. שמור עם שם 001.webp

#### באמצעות כלי שורת פקודה:
```bash
# התקנת cwebp (Google WebP tools)
# Windows: https://developers.google.com/speed/webp/download

# המרה של JPG ל-WEBP
cwebp -q 85 input.jpg -o 001.webp
```

#### באמצעות Python (PIL/Pillow):
```python
from PIL import Image

img = Image.open("input.jpg")
img = img.resize((1200, 1697), Image.Resampling.LANCZOS)
img.save("static/pages/001.webp", "WEBP", quality=85, method=6)
```

## טיפים לעיצוב

### יחס גובה-רוחב:
הקטלוג משתמש ביחס **1:1.414** (יחס A4 סטנדרטי) - זה נותן מראה של עיתון/מגזין מקצועי.

### איכות תמונה:
- **WEBP** מומלץ כי הוא נותן איכות גבוהה עם משקל קטן (חצי מגודל JPG)
- אם יש לך הרבה תמונות, WEBP יטען הרבה יותר מהר

### עיצוב הדפים:
- השאר שוליים של לפחות 50 פיקסלים מכל צד (כדי שהתוכן לא ייחתך)
- טקסט חשוב לא צריך להיות קרוב מדי למרכז (קו הקיפול)
- עמוד 1 הוא הכריכה - שים את הלוגו והכותרת הראשית שם

## פתרון בעיות

### התמונות לא נטענות?
1. וודא ששמות הקבצים הם `001.jpg`, `002.jpg` וכו' (3 ספרות)
2. וודא שהתמונות נמצאות בתיקייה `static/pages/`
3. רענן את הדפדפן (Ctrl+F5)

### הדפדוף לא עובד?
1. בדוק את ה-Console בדפדפן (F12)
2. וודא שיש חיבור אינטרנט (הספרייה נטענת מ-CDN)

### האתר לא עולה?
1. וודא ש-FastAPI מותקן: `pip install -r requirements.txt`
2. וודא שפורט 8000 לא תפוס על ידי תוכנה אחרת
3. הרץ: `python app.py`
